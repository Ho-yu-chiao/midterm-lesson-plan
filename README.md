# 期中教學教案與資源庫 (Midterm Lesson Plans)

歡迎造訪 **期中教學教案與資源庫**！本專案旨在系統化設計、整理並公開分享國中小階段之期中教案、STEAM 跨域專案、學習活動與評量工具，提供教育工作者自由參考、教學應用與交流。

🌐 **線上公開教案網頁**：[https://ho-yu-chiao.github.io/midterm-lesson-plan/](https://ho-yu-chiao.github.io/midterm-lesson-plan/)

## 📚 收錄教案列表

本專案教案依據 108 課綱核心素養規劃，目前已收錄：

### 1. 🌟 [國小科技資訊教育教案：投石戰車](./plans/01-投石戰車-國小科技資訊教育教案.md)
- **設計團隊**：周昱芊、陳新宜、何羽喬、許睿芯
- **適用對象**：國小六年級
- **領域與節數**：自然科學領域（1 節）＋ 資訊科技領域（4 節），合計 5 節（200 分鐘）
- **核心概念**：
  - **科學**：彈性位能與動能轉換、槓桿原理（支點、施力點、抗力點）。
  - **技術**：Tinkercad 3D 繪圖設計、數位拋射模擬軟體與數據量測。
  - **工程**：投石機結構組裝、不同彈性強度橡皮筋之實測與改裝。
  - **數學**：拋射落點數據收集、統計折線圖繪製與最佳條件分析。
- **附錄資源**：包含 4 份完整課堂學習單（電腦模擬紀錄表、設計圖稿單、實測紀錄表、自評與互評量表）。

### 2. [運算思維與演算法基礎探究](./plans/02-運算思維與演算法期中教學設計.md)
- **領域**：科技領域 / 資訊科技（國中七至八年級 / 高中一年級）
- **重點**：日常生活流程圖繪製、循序搜尋 vs 二分搜尋、氣泡排序模擬與時間複雜度初探。

### 3. [科普文本閱讀理解與資訊素養](./plans/03-科普閱讀與資訊素養期中教案.md)
- **領域**：語文與資訊領域跨域探究
- **重點**：科普文章結構拆解、圖表陷阱判讀、橫向閱讀法（Lateral Reading）與事實查核任務。

## 🚀 線上瀏覽與日常工作

1. **線上瀏覽**：直接造訪 [GitHub Pages 網站](https://ho-yu-chiao.github.io/midterm-lesson-plan/)，可在線上直接切換教案、即時搜尋關鍵字、查看流程圖與圖表、列印或匯出 PDF。
2. **本機預覽**：直接以瀏覽器開啟根目錄的 `index.html`。
3. **AI 協同工作**：
   - 輸入「**開工**」：自動檢查專案進度與 Git 狀態。
   - 輸入「**收工**」：自動過濾敏感資訊並確認 Git 變更推送。
