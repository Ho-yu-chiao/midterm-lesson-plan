# 投石戰車 STEAM 科技探索館 (Catapult STEAM Lab)

歡迎造訪 **投石戰車 STEAM 科技探索館**！本專案為國小六年級科技資訊教育之跨領域期中教案與互動式教材平台，結合**自然科學領域（1 節）**與**資訊科技領域（4 節）**，共 5 節（200 分鐘）之完整 STEAM 探究課程。

🌐 **線上公開網站與互動小遊戲**：[https://ho-yu-chiao.github.io/midterm-lesson-plan/](https://ho-yu-chiao.github.io/midterm-lesson-plan/)

---

## 🎮 網站特色功能

1. **🏰 投石車彈道物理模擬小遊戲**：
   - **實體物理運算**：即時模擬拋物線彈道軌跡、落點距離 ($X$) 與最高高度 ($H$)。
   - **發射參數調節**：自由更換橡皮筋彈力強度（弱/中/強/特強）、投射仰角（15°~80°）與投擲物材質（輕木球、重石塊）。
   - **目標城堡挑戰**：隨機產生距離目標，考驗學生透過物理概念微調命中城堡！
   - **即時音效回饋**：內建 Web Audio API 音效合成（發射風切聲、落地撞擊聲、命中歡呼聲）。
2. **📊 課堂實驗數據紀錄表 & 即時折線圖**：
   - 對應教案附錄一《實驗紀錄表-電腦模擬》，學生在線上實驗後可一鍵記錄數據。
   - 自動即時繪製「彈力強度與拋射距離折線關係圖」，落實資訊科技數據視覺化素養。
3. **📖 完整教案全覽 & 學習單一鍵列印**：
   - 收錄完整 5 節課教學流程、雙向細目表、Mermaid 課程架構圖與 4 份課堂專用學習單。
